Diagnostic et limites du mode gratuit

Le mode gratuit utilise la reconnaissance du navigateur, qui peut transmettre l’audio à son fournisseur. Ni une voix tunisienne native ni l’écoute simultanée parfaite sur tous les téléphones ne sont garanties. Les données de commande restent sur cet appareil en mode GitHub Pages. Aucun enregistrement audio n’est conservé par Ordely.
